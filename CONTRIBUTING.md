# Contributing

Issues and pull requests are welcome on https://github.com/Harry0052/buildcoach.

## Setup

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

## Checks

```bash
python -m ruff check src tests scripts
python -m ruff format --check src tests scripts
python -m pytest -q
python -m buildcoach demo --output out/demo
```

The demo must keep occluded and contradictory completions at zero.

## Fixtures

Photos under `src/buildcoach/fixtures/images/` are synthetic and generated by `scripts/render_fixtures.py` with seed `20261123`. Do not add photos of people, copyrighted manuals, or Assembly101 and IKEA images. After regenerating, commit the images and the updated `MANIFEST.json` checksums.

## Secrets

Do not commit credentials, tokens, or private camera dumps. The CI workflow has `contents: read` and no secrets.
