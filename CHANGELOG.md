# Changelog

## 0.1.0

First working release of BuildCoach.

- Desk Ledge practice kit with three steps and original tag sheets.
- Local ArUco checks for identity, co-visible tags, relative edge angle, and placement.
- A hidden required tag requests a named view and does not complete the step.
- Disagreeing clean views request a retake. Detection area is not used to pick a winner.
- Mirrored photos, duplicate tag ids, implausible layouts, and undersized tags fail on their own.
- Command line and a loopback upload page share one report schema.
- Synthetic fixtures only. No phone-camera validation and no claim about strength or fastening.
